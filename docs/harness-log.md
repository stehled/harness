# Harness log

Each rule in this harness exists because something went wrong. This log names the failure, the rule
and how the harness enforces it. The first entries come from a private SaaS that agents
built with this harness: about 290 merged pull requests in eight weeks. The pull request numbers
refer to that repository.

| #   | Failure                                                                                                                                                      | Rule                                                                 | Enforcement                                                                                                 |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 1   | The second agent that started the stack failed on a port in use. Worse, it sometimes connected to the database of the first agent. (#63)                     | Each worktree has a slot: its own ports and its own Compose project. | `tools/worktree/`, `pnpm env:init`, port literals forbidden                                                 |
| 2   | An example in `CONTRIBUTING.md` put a worktree beside the repository. Agents copied the example. (#112)                                                      | Worktrees go under `.claude/worktrees/`.                             | `enforce-git-conventions` rewrites the path                                                                 |
| 3   | Pull requests opened as ready, and each push started the full CI. (#112)                                                                                     | A pull request opens as a draft.                                     | `enforce-git-conventions` adds `--draft`                                                                    |
| 4   | Agents ran `git checkout -b` in the shared main checkout. A concurrent agent did a hard reset there and erased uncommitted work of a different agent. (#116) | Ticket work never happens in the main checkout.                      | the hook rewrites the checkout into a worktree, and `block-main-checkout-edits` refuses edits as a backstop |
| 5   | Finished work stayed unpushed until somebody asked. (#116)                                                                                                   | Push and open the draft when the work is done.                       | the `Stop` hook pushes and opens the draft                                                                  |
| 6   | After a `cd` into a worktree, every hook failed to load, without a visible error. The hooks used a relative path. (#229)                                     | A hook command uses an absolute path.                                | `"$CLAUDE_PROJECT_DIR"` in `.claude/settings.json`                                                          |
| 7   | The rolled-back transaction of Seam 1 could not test a row lock. No test covered `FOR UPDATE`. (#110)                                                        | A real race gets a test in concurrent mode.                          | `seamOne({ concurrent: true })`                                                                             |
| 8   | Ten pull requests opened within twenty minutes. Most pairs collided on the schema, the journal and the barrels. (#118)                                       | Plan a batch before it starts.                                       | the `plan-waves` skill and `docs/parallel-orchestration.md`                                                 |
| 9   | The CI minutes ran out. (#190)                                                                                                                               | CI runs only the cheap checks. Seam 1 and Seam 3 run on request.     | `ci.yml`, `pnpm verify` as local evidence                                                                   |
| 10  | The comments in code needed a full rewrite into simplified English (#281), and later a full removal (#635).                                                  | No comments in code without approval.                                | `AGENTS.md`, `CONTRIBUTING.md`, review                                                                      |

## Found when the harness moved to this repository

| #   | Failure                                                                                                                                                                                                                                                                                                                           | Rule                                                                                                                          | Enforcement                                                                                               |
| --- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 11  | The hooks had no tests. They were tested by hand with piped JSON.                                                                                                                                                                                                                                                                 | Each hook keeps its decision in a pure function with a Seam 2 test.                                                           | `tools/hooks/*.test.mjs`                                                                                  |
| 12  | The eval corpus found four defects in the hook that ran for two months. `--draft` went to a later command (`gh pr create --fill && gh pr view --web`). A `--draft` in a later command stopped the rewrite. `&&` without spaces hid a `git worktree add`. A rewrite dropped the other fields of the tool input, such as `timeout`. | A hook rewrites only its own statement and keeps the rest of the input.                                                       | `evals/hooks/cases.json`, 26 cases, run by `pnpm eval` and by the tests                                   |
| 13  | The hook and the slot tool each had a copy of the branch convention and the project name.                                                                                                                                                                                                                                         | One configuration file.                                                                                                       | `harness.config.json`, read by the hooks and by `tools/worktree/`                                         |
| 14  | Nobody had measured the cards of `plan-waves`. The eval on 14 tickets showed a precision of 87% for `certain` lines, but a recall of 47%. The cards missed module files, contracts and tests.                                                                                                                                     | Each card follows the "Always with" table. Measure the cards after each batch.                                                | `evals/plan-waves/run.mjs`, `SURFACE-MAP.md`, `evals/plan-waves/RESULTS.md`                               |
| 15  | A review found that the hook dropped the quotes of a branch name when it built the new command. `git switch -c 'feat/1-a$(id)'` became a command that ran `id`.                                                                                                                                                                   | A hook never puts a word into a command unless the word is plain.                                                             | `isPlainWord` in `tools/hooks/git-conventions.mjs`, 3 `shell-injection` cases in `evals/hooks/cases.json` |
| 16  | The hook allowed the whole rewritten command without a prompt, also the part that it did not rewrite: `git switch -c x && rm -rf ~`.                                                                                                                                                                                              | A hook allows only a command that holds nothing but the statements that it rewrites. The rest needs the decision of a person. | `isOnlyRewrittenStatements` in `tools/hooks/git-conventions.mjs`: otherwise `permissionDecision` is `ask` |
